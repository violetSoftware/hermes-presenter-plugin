# Privacy inventory

Positive inventory: native plugin registration/manifest, bundled caller transport and generic sample; selected runtime engine modules; browser application/core/controller/transcription source; layout/schema resources; purple-only system-font CSS and neutral mark; pinned dependency lock; reproducible verification scripts and neutral setup documentation.

Excluded: Git metadata, installed libraries, credentials/config/session stores, user talks and private showcase, private profiles/addresses, research/internal evidence, legacy budget policies and native-session creation launchers, employer styles/logo/fonts, original public presentation collection and build outputs. No source-root symlink is an export input. No original-checkout path is stored in the candidate. The original source checkout is not the distribution repository.

All exported text is scanned before writing the final manifest for personal names, email addresses, profile paths, mounted checkout paths, local/private host addresses, credential-like values, known private profile/card identifiers and employer typography/branding. Verification uses only explicit synthetic caller/input/admission identifiers. violetSoftware is the explicitly approved public maintainer account and copyright identity. Public network destinations retained are the fixed ElevenLabs API endpoints; package resolution URLs in the lockfile are upstream npm registry URLs; documentation links are official upstream guidance and the approved public repository; example.org and absolute placeholder paths are nonsecret examples. Identifier presence is not by itself a privacy breach: JSON API field names such as session_id, runtime-derived session references, HTTP localhost bind and cryptographic integrity values are required protocol/configuration data, not saved user sessions or secrets.

THIRD-PARTY.json is a metadata inventory, not bundled dependencies. EXPORT-MANIFEST.json lists every other file's SHA-256 and size; it contains no absolute source location. The exporter itself is retained in the private source tree for review, not copied into the candidate, because it refers to private-only exclusion rules. Treat a scanner pass as a bounded tool finding, not certification. The publisher must review identities, rights and public repository content before release.
