# Third-party dependency notices

Project source is provided under the MIT License in LICENSE. Third-party dependencies retain their respective licenses.

THIRD-PARTY.json enumerates every retained lockfile package name/version/license from the already-resolved graph. Dependency source/binaries are not bundled. The direct application/build dependencies Ajv, Handlebars, Reveal.js, Undici and Vite declare MIT in that graph; optional build binaries and transitive packages retain their own licenses (including Apache-2.0, BSD, MPL-2.0 and other SPDX expressions, as enumerated). Verification-only Playwright declares Apache-2.0. Upstream license notices must be retained when installing or redistributing those dependencies. This inventory is not a legal review or an assertion of rights in upstream code. The built browser includes Reveal/Handlebars code and requires its upstream notices in any final binary release.
